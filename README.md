# Ace Workplace Solutions — Codex Handoff Pack

Use these files together for a one-shot homepage build that stays close to the locked strategy.

## Recommended upload order to Codex
1. `PROJECT_BRIEF.md`
2. `HOMEPAGE_SOURCE_OF_TRUTH.md`
3. `DESIGN_SYSTEM_AND_LAYOUT_RULES.md`
4. `AGENTS.md`
5. `ONE_SHOT_BUILD_PROMPT.md`

## Goal
Build a homepage for Ace Workplace Solutions that is:
- premium but practical
- visually calm and architectural
- commercially clear
- quote-first, viewing-second
- mobile-strong

## Important
This pack is designed to get Codex as close to publish-ready as possible in one shot.
It still contains a few intentional placeholders where operational truth must be confirmed later:
- warranty
- lead time
- service coverage
- showroom details
- acoustic / ventilation proof assets
- real project logos / testimonials / case studies

Codex should build the page so these can be inserted later without redesign.

## Included files
- `PROJECT_BRIEF.md` — business and conversion context
- `HOMEPAGE_SOURCE_OF_TRUTH.md` — locked homepage structure and copy direction
- `DESIGN_SYSTEM_AND_LAYOUT_RULES.md` — visual system, layout, mobile behavior, components
- `AGENTS.md` — hard guardrails for Codex
- `ONE_SHOT_BUILD_PROMPT.md` — exact prompt to paste into Codex
